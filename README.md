# REDLINE Android companion

Android 15-compatible floating gaming companion demo.

## Build using only your phone
1. Open the Actions tab in this repository.
2. Select **Build REDLINE APK**.
3. Tap **Run workflow**.
4. Open the completed run and download the **REDLINE-debug-apk** artifact ZIP.
5. Extract the ZIP and install the APK on your Android phone.

## Use
1. Open REDLINE.
2. Tap **Allow display over other apps** and enable permission.
3. Return and tap **Start REDLINE floating menu**.
4. Drag the red R bubble and tap it to expand/collapse the menu.

This is a standalone companion overlay. It does not inject into games, inspect game memory, automate gameplay, reveal live opponents, or bypass anti-cheat systems.
